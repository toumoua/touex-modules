TouEX

TouEX2 · TouEX2 Manager · module repository for Geely IHU629G (Android 9 / Flyme Auto E)

TouEX is the distribution repository behind the TouEX2 Manager app (com.touex.manage). It holds index.json plus the payload files (APK packages and RRO overlays) that the app downloads, verifies with SHA-256 and installs on the car head unit. No source code lives here.

Supported hardware

  • Head unit: Geely IHU629G — Android 9, PQ2A.190405.003
  • System: Flyme Auto E 1.8.0 — software version 1111
  • The bootstrap OTA package only applies to version 1111 (do not flash it on 1114 / 1121)

How modules are installed

  1. Flash the bootstrap OTA once from USB — it installs TouEX2 Manager by itself.
  2. In the car: open TouEX2 Manager → check for updates → enable the module you want.
  3. Every change has an off switch: disabling a module restores the stock app / overlay state.
Compatibility: modules are tested on Geely IHU629G, Android 9 / Flyme Auto E. Modules that replace system apps (Settings, launcher, ConnAdaptor, Energy) are tied to the firmware and app versions — check your car version before installing.
